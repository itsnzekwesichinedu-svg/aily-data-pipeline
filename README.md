# Public Data Pipeline & Cleaning Script

## Overview
This repository fetches a public dataset, cleans and validates it using Python and Pandas, and outputs a refined dataset for downstream analysis or ingestion.

## Features
- **Data Acquisition:** Automatically pulls public data from source API/URL.
- **Data Cleaning:** Handles missing values, standardizes column formats, and formats timestamps/numeric fields.
- **Validation Checks:** Verifies schema structure, checks for duplicate entries, and ensures zero missing values in critical fields.

## Tech Stack
- Python 3.x
- Pandas
